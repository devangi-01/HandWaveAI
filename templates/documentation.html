HandWave AI Documentation

HandWave AI is an innovative platform that uses advanced machine learning to recognize and interpret hand gestures, making technology more accessible and interactive.

Project Overview

HandWave AI is a final year project developed by a team of three students. The platform consists of three main applications that leverage computer vision and machine learning to interpret hand gestures for different purposes:

  • Math Solver

    Draw mathematical equations with hand gestures and get instant solutions using AI.

  • Sign Language Recognition

    Translate sign language gestures into text in real-time with our advanced AI technology.

  • Gesture Quiz

    Test your knowledge with interactive quizzes where you answer by showing hand gestures.

Getting Started

HandWave AI is a web-based application built with Django. To get started, you'll need to have a webcam connected to your device and a modern web browser.

System Requirements

  • Modern web browser (Chrome, Firefox, Edge, Safari)
  • Webcam
  • Stable internet connection
  • Good lighting conditions for optimal hand detection

Browser Permissions

When you first use any of the HandWave AI applications, your browser will ask for permission to access your webcam. You must allow this permission for the applications to function properly.

HandWave AI respects your privacy. Video processing happens in real-time on your device, and video data is not stored or sent to external servers except when explicitly using the AI analysis features.

Math Solver

Overview

The Math Solver application allows users to draw mathematical equations using hand gestures and get instant solutions powered by Google's Gemini AI. It's designed to make solving complex math problems more interactive and accessible.

Features

  • Draw Equations

    Use your index finger to draw mathematical equations on the screen.

  • Erase Mistakes

    Use two fingers to erase parts of your equation.

  • Solve with Thumbs Up

    Give a thumbs up gesture to send your equation to the AI for solving.

  • Reset Canvas

    Show all five fingers to clear the canvas and start over.

  • Image Upload

    Upload images of math problems for AI analysis.

How to Use

  1. Position Your Hand

    Make sure your hand is clearly visible in the webcam view.

  2. Draw Your Equation

    Raise your index finger and draw your mathematical equation on the screen. Keep your hand steady for better recognition.

  3. Erase if Needed

    Raise your index and middle fingers to erase parts of your equation.

  4. Solve the Equation

    Give a thumbs up gesture (only thumb raised) to send your equation to the AI for solving.

  5. View the Solution

    The AI-generated solution will appear in the solution panel on the right.

  6. Reset and Try Again

    Show all five fingers to clear the canvas and start a new equation.

Tip: For best results, write clearly and leave space between symbols. The AI works better with well-formed equations.

Technical Details

Technologies Used

  • Hand Tracking: cvzone.HandTrackingModule (based on MediaPipe)
  • AI Solution: Google's Gemini AI (Gemini 1.5 Flash)
  • Backend: Django with OpenCV for image processing
  • Frontend: HTML, CSS, JavaScript

How It Works

The Math Solver uses computer vision to track hand movements and gestures in real-time. Here's the technical workflow:

  1. The webcam captures video frames which are processed by OpenCV.
  2. The HandTrackingModule detects hand landmarks and recognizes gestures.
  3. When drawing (index finger up), the system tracks the fingertip position and draws lines on a canvas.
  4. When erasing (two fingers up), it draws black lines to erase content.
  5. When a thumbs up gesture is detected, the canvas image is sent to Google's Gemini AI.
  6. Gemini AI analyzes the equation and returns a solution, which is displayed to the user.

Sign Language Recognition

Overview

The Sign Language Recognition application uses machine learning to recognize and interpret American Sign Language (ASL) alphabet gestures in real-time. It helps bridge communication gaps for the deaf and hard of hearing community.

Features

  • Real-time Recognition

    Instantly recognizes ASL alphabet signs (A-Z) with confidence scores.

  • Manual Detection

    Detect Sign button for capturing and analyzing specific gestures.

  • Sign History

    Keeps track of recently detected signs to form words and sentences.

  • Visual Alphabet

    Reference grid of all alphabet letters with active highlighting.

How to Use

  1. Position Your Hand

    Place your hand in the center of the camera view with good lighting for best results.

  2. Form a Sign

    Form an ASL alphabet sign with your hand and hold it steady for the AI to recognize.

  3. Detect Sign

    Click the "Detect Sign" button to capture and analyze the current hand gesture, or wait for automatic detection.

  4. View Results

    See the detected letter, confidence level, and watch as it's added to your sign history.

  5. Form Words

    Continue making signs to form words and sentences using the history feature.

Tip: For better recognition, ensure your hand is well-lit and against a plain background. Practice each sign slowly at first.

Technical Details

Technologies Used

  • Hand Tracking: MediaPipe Hands
  • Machine Learning: TensorFlow/Keras model trained on ASL gestures
  • Backend: Django with OpenCV for image processing
  • Frontend: HTML, CSS, JavaScript

How It Works

The Sign Language Recognition system uses a pre-trained neural network to classify hand gestures:

  1. MediaPipe Hands detects and tracks 21 hand landmarks in real-time.
  2. These landmarks (x, y, z coordinates) are extracted and normalized.
  3. The normalized landmarks are fed into a trained neural network model.
  4. The model predicts the most likely ASL letter with a confidence score.
  5. Results are displayed in real-time and added to the history if confidence exceeds 50%.

Gesture Quiz

Overview

The Gesture Quiz application combines learning with interactive gesture recognition. Users answer multiple-choice questions by showing a specific number of fingers, making the quiz experience engaging and fun.

Features

  • Interactive Questions

    Multiple-choice questions with visual answer options.

  • Gesture Controls

    Answer by showing 1-4 fingers to select options A-D.

  • Sound Effects

    Audio feedback for selections, correct/incorrect answers, and quiz completion.

  • Score Tracking

    Real-time score calculation and final results display.

How to Use

  1. Start the Quiz

    Load the Gesture Quiz page to begin. The first question will appear automatically.

  2. Read the Question

    Each question has four possible answers labeled A, B, C, and D.

  3. Answer with Gestures

    • 1 finger up: Select option A
    • 2 fingers up: Select option B
    • 3 fingers up: Select option C
    • 4 fingers up: Select option D
    • Fist (0 fingers): Reset selection

    Important: Keep your thumb down when selecting answers.

  4. Confirm Your Answer

    Hold your gesture steady for 2 seconds to confirm your answer. You'll hear a sound effect indicating your selection.

  5. Continue the Quiz

    After answering, the next question will appear automatically.

  6. View Your Results

    After completing all questions, you'll see your final score and performance evaluation.

Tip: Make sure your fingers are clearly visible and separated for accurate detection. If you're having trouble, try adjusting your hand position or lighting.

Technical Details

Technologies Used

  • Hand Tracking: cvzone.HandTrackingModule (based on MediaPipe)
  • Audio: playsound library for sound effects
  • Data Storage: CSV files for quiz questions
  • Backend: Django with session management
  • Frontend: HTML, CSS, JavaScript

How It Works

The Gesture Quiz combines computer vision with a quiz system:

  1. Quiz questions are loaded from a CSV file into the application.
  2. The HandTrackingModule detects hand landmarks and counts raised fingers.
  3. The system specifically checks for fingers 1-4 (index to pinky) being raised while the thumb is down.
  4. When a valid gesture is detected, the corresponding answer is selected.
  5. After a 2-second hold, the answer is confirmed and evaluated.
  6. The system plays appropriate sound effects and updates the score.
  7. Quiz progress is stored in the Django session to maintain state.

Installation Guide

Follow these steps to set up HandWave AI on your local machine for development or testing purposes.

Prerequisites

  • Python 3.8 or higher
  • pip (Python package manager)
  • Git
  • Webcam

Installation Steps


# 1. Clone the repository
git clone https://github.com/devangi-01/HandWaveAI.git
cd handwave-ai

# 2. Create a virtual environment
python -m venv venv

# 3. Activate the virtual environment
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate

# 4. Install dependencies
pip install -r requirements.txt

# 5. Set up environment variables
# Create a .env file in the project root and add:
GEMINI_API_KEY=your_gemini_api_key

# 6. Run migrations
python manage.py migrate

# 7. Start the development server
python manage.py runserver

Configuration

You'll need to configure the following:

  • Gemini API Key: Obtain an API key from Google AI Studio and add it to your environment variables.
  • Quiz Questions: Customize the quiz questions by editing the CSV file in the gesture_quiz directory.
  • Camera Settings: If needed, adjust camera settings in the views.py files of each application.
