Welcome to ASL Recognition

About This Project

This application uses computer vision and machine learning to recognize American Sign Language (ASL) gestures in real-time through your webcam.

The system can identify various ASL signs and display the corresponding meaning along with a confidence score.

How to Use

  1. Go to the Recognition page
  2. Allow camera access when prompted
  3. Position your hand in the frame
  4. Make ASL signs and see the recognition results in real-time
